3619. Count Islands Divisible by K
LeetCode Daily Challenge · Graph Traversal & Connected Components
Medium 2026-10-26
Array Depth-First Search (DFS) Breadth-First Search (BFS) Matrix Traversal In-Place Mutation
🎯 1. Problem Statement & Objective
Given an m x n grid and an integer k. An island is a 4-directionally connected cluster of positive numbers (grid[r][c] > 0). The total value of an island is the sum of all cell values in that island.
Goal: Return the count of islands whose total value is evenly divisible by k (total_value % k == 0).
🧠 2. Topics You Need to Know
  • 2D Matrix as Implicit Graph: Each cell is connected to its 4 cardinal neighbors (up, down, left, right).
  • Connected Components: Grouping isolated sets of connected vertices.
  • In-Place Visited Marking: Changing processed cells to 0 avoids allocating extra memory.
  • Modulo Arithmetic: Validating island_sum % k == 0.
💡 3. Core Concept
An extension of Number of Islands (#200) with an accumulator: $$\text{Total Value}(\text{Island}) = \sum_{(r, c) \in \text{Island}} \text{grid}[r][c]$$ Iterate over all cells. When an unvisited land cell (> 0) is found, initiate an iterative DFS stack, collect all neighbor values, zero them out, and test if sum % k == 0.
⚡ 4. Trick to Remember (Mental Model)
"Sink & Sum on Sight": Whenever you spot a cell > 0, you have struck a new island! Sink the cell to 0 immediately upon discovery to prevent endless loops. Accumulate the weights of the entire component. When the DFS stack empties, apply one single test: if (sum % k == 0) ans++. Use an explicit stack to stay safe from recursion depth limits!
🔍 5. Example Walkthrough
grid = [[0,2,1],[0,0,3],[4,2,0]], k = 3
• Island A: (0,1)=2, (0,2)=1, (1,2)=3
  Sum = 2+1+3 = 6 (6 % 3 == 0) ✔️
• Island B: (2,0)=4, (2,1)=2
  Sum = 4+2 = 6 (6 % 3 == 0) ✔️
Result = 2 Islands
⏱️ 6. Complexity Guarantee
Time: O(M × N) — Single full scan
Space: O(M × N) — Iterative stack
Auxiliary Space is O(1) beyond the traversal stack since visited nodes are marked in-place.

💻 7. Optimal Multi-Language Implementation
# Python 3 — Iterative DFS with In-Place Visited Invalidation
class Solution:
    def countIslands(self, grid: List[List[int]], k: int) -> int:
        if not grid or not grid[0]: return 0
        m, n, ans = len(grid), len(grid[0]), 0

        for r in range(m):
            for c in range(n):
                if grid[r][c] > 0:
                    island_sum, stack = grid[r][c], [(r, c)]
                    grid[r][c] = 0  # Mark visited in-place
                    
                    while stack:
                        cr, cc = stack.pop()
                        for dr, dc in ((-1, 0), (1, 0), (0, -1), (0, 1)):
                            nr, nc = cr + dr, cc + dc
                            if 0 <= nr < m and 0 <= nc < n and grid[nr][nc] > 0:
                                island_sum += grid[nr][nc]
                                grid[nr][nc] = 0  # Sink immediately
                                stack.append((nr, nc))

                    if island_sum % k == 0:
                        ans += 1
        return ans
// C++17 Solution
int countIslands(vector<vector<int>>& g, int k) {
    int m = g.size(), n = g[0].size(), ans = 0;
    int dr[4] = {-1,1,0,0}, dc[4] = {0,0,-1,1};
    for (int r = 0; r < m; ++r) {
        for (int c = 0; c < n; ++c) {
            if (g[r][c] > 0) {
                long long sum = g[r][c]; g[r][c] = 0;
                stack<pair<int,int>> st; st.push({r, c});
                while (!st.empty()) {
                    auto [cr, cc] = st.top(); st.pop();
                    for (int i = 0; i < 4; ++i) {
                        int nr = cr + dr[i], nc = cc + dc[i];
                        if (nr >= 0 && nr < m && nc >= 0 && nc < n && g[nr][nc] > 0) {
                            sum += g[nr][nc]; g[nr][nc] = 0; st.push({nr, nc});
                        }
                    }
                }
                if (sum % k == 0) ans++;
            }
        }
    }
    return ans;
}
