1. Two Sum

Hash Table & Complement Search · Array Foundation
Easy
🎯 Problem Goal: Given an integer array nums and integer target, return indices of two numbers such that they add up to target. Exactly one solution exists.
🧠 Topics Need to Know:
  • Hash Table O(1) average lookup
  • Complement: target - current_num
  • One-Pass Invariant (prevent self-pairing)
💡 Core Concept:

Convert pair search to key search: instead of $O(N^2)$ brute force, check if complement was already seen in $O(1)$ time using a Hash Map.

⚡ Trick to Remember (Interview Intuition):

"Look Back for the Complement": Don't search forward! As you walk, ask: "Did I already see my missing puzzle piece target - num?" If yes, boom! You found the pair. If not, record your own index and continue.

🔍 Example:
nums = [2, 7, 11, 15], target = 9
• i=0, num=2: need 7. Not in map. seen[2]=0.
• i=1, num=7: need 2. In map at index 0!
Return [0, 1]
⏱️ Complexity:
• Time: O(N) — Single linear pass.
• Space: O(N) — Stores up to N elements.

# Python 3
class Solution:
    def twoSum(self, nums: List[int], target: int) -> List[int]:
        seen = {}
        for i, num in enumerate(nums):
            complement = target - num
            if complement in seen:
                return [seen[complement], i]
            seen[num] = i
        return []
// C++
vector<int> twoSum(vector<int>& nums, int target) {
    unordered_map<int, int> seen;
    for (int i = 0; i < nums.size(); ++i) {
        int comp = target - nums[i];
        if (seen.count(comp)) return {seen[comp], i};
        seen[nums[i]] = i;
    }
    return {};
}
