1385. Find the Distance Value Between Two Arrays

LeetCode Daily Challenge · Array, Two Pointers, Binary Search, Sorting

🎯 Problem Goal:
Given two integer arrays `arr1` and `arr2`, and the integer `d`, return the distance value between the two arrays . The distance value is defined as the number of elements `arr1[i]` such that there is not any element `arr2[j]` where `|arr1[i]-arr2[j]| <= d`. class Solution:
    def findTheDistanceValue(self, arr1: list[int], arr2: list[int], d: int) -> int:
        arr2.sort()
        count = 0
        import bisect
        
        for x in arr1:
            # Find the first index in arr2 where value >= x
            idx = bisect.bisect_left(arr2, x)
            ok = True
            
            # Check the element at idx (first >= x)
            if idx < len(arr2) and arr2[idx] - x <= d:
                ok = False
            # Check the element just before idx (largest < x)
            if idx > 0 and x - arr2[idx - 1] <= d:
                ok = False
            
            if ok:
                count += 1
        
        return count
