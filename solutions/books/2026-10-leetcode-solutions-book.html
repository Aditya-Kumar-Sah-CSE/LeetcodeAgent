Chapter 1: 3619. Count Islands Divisible by K

Medium

Concept Used: Implicit Graph, 4-Directional Connected Components, In-Place Visited Invalidation.

🇮🇳 Hinglish Trick to Remember:

Cell ko visit karte hi 0 kar do taaki dubara count na ho! DFS se pura island traverse karke unka sum nikaalo, aur aakhri me check karo island_sum % k == 0. 

class Solution:
    def countIslands(self, grid: List[List[int]], k: int) -> int:
        if not grid or not grid[0]: return 0
        m, n, ans = len(grid), len(grid[0]), 0
        for r in range(m):
            for c in range(n):
                if grid[r][c] > 0:
                    s, st = grid[r][c], [(r, c)]
                    grid[r][c] = 0
                    while st:
                        cr, cc = st.pop()
                        for dr, dc in ((-1,0),(1,0),(0,-1),(0,1)):
                            nr, nc = cr+dr, cc+dc
                            if 0 <= nr < m and 0 <= nc < n and grid[nr][nc] > 0:
                                s += grid[nr][nc]; grid[nr][nc] = 0; st.append((nr, nc))
                    if s % k == 0: ans += 1
        return ans
Time Complexity: O(M × N) · Space Complexity: O(M × N)

Chapter 2: 1. Two Sum

Easy

Concept Used: Hash Table Complement Search ($O(1)$ amortized lookup).

🇮🇳 Hinglish Trick to Remember:

Aage dhoondhne ke bajaye peeche dekho! target - num agar pehle dekha hai dictionary me, toh dono index return karo. 

class Solution:
    def twoSum(self, nums: List[int], target: int) -> List[int]:
        seen = {}
        for i, num in enumerate(nums):
            diff = target - num
            if diff in seen:
                return [seen[diff], i]
            seen[num] = i
        return []
Time Complexity: O(N) · Space Complexity: O(N)
